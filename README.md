# Calculadora de IMC

Atividade prática: página Web interativa com HTML, CSS e JavaScript.

## Como usar
Abra o arquivo `index.html` no navegador, digite seu peso e altura e clique em **Calcular**.

## Requisitos atendidos
| Requisito | Onde está |
|---|---|
| Estrutura HTML organizada | `index.html` (header, main, section, footer) |
| Estilos CSS básicos | `style.css` |
| Variável e função JavaScript | `script.js` (`const campoPeso`, `function calcularIMC`) |
| Botão com evento de clique | `addEventListener("click", ...)` |
| Alteração no conteúdo da página | resultado exibido na div `#resultado` e linha destacada na tabela |
| Formulário / campo de entrada | campos de peso e altura |
| Validação ou cálculo | validação dos campos + cálculo do IMC |
